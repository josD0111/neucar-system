# Planificacion de la reunion del sprint 03.
*Este documento busca describir los puntos a tratar en la reunión que se tendra para finalizar el sprint 03*

## Orden:
### 1 - Corroborar el entendidimiento que se tiene actualmente del negocio:
- Verificar el funcionamiento de compras de productos y su posterior asignación de garantías en el negocio.
- Describir el ejemplo de la compra de batería desde varios proveedores con un precio compra y garantia distintos. Con el fin de validar si el modelo por lotes tiene sentido o si en todo caso fue una sobre-complicación.

### 2 - Realizar una presentación del sistema
Mostrar los cambios desde la última reunión:
- Mostrar la página de ventas, verificar si el flujo le parece práctico.
- Mosrar la página de ventas desde el punto de vista del empleado.
- Mostrar la página de compras y el historial de compras.
- Mostrar la página de servicios y el funcionamiento del registro de kilometraje.

### 3 - Solicitarle al stakeholder que pruebe el sistema.
El dueño del taller debe probar cada punto presentado para que nos de su opinión de si le parece correcto o si hace falta ajustar algo más.
Este punto se puede realizar de manera intercalada con el punto 2.

### 4 - Muestra de prototipos para la pantalla de ventas.
Una vez el stakeholder haya probado la pantalla de ventas se le debe preguntar sobre como prefiere operar con el sistema, si le molesta el módelo por lotes o si le parece aceptable.
Entre los prototipos a mostrar, ir primero con la versión sencilla y luego ir directo a la versión con lotes editables, dejar el prototipo de lotes automátizados solo si le intereza.

### 5 - Extras
- Sería bueno revisar el sistema anterior para ver una vez más su funcionamiento y comparlo con nuestro sistema.
