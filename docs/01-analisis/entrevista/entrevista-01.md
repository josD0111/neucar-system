- ¿Quienes utilizan el sistema?
> El dueño del local, su esposa (utilizando el código del dueño) y un empleado (Rey).

- ¿El empleado tiene limitaciones?
> El empleado solo tiene acceso a las funciones basicas. (ver los precios y stock de las mercaderias, no puede descontar mercaderias, no puede dar descuentos, el puede vender por el precio base).

- ¿Que se espera que realice el sistema?
> Control de stock, (se puede ver las cantidades de las mercaderias, las disponibles) El dueño solo quiere ver las mercaderias que estan en existencia.
> El sistema debe permitir la compra a credito, saber los datos del cliente, que compro, su saldo y poder imprimirlo para que luego el cliente lo firme.
> Se espera que el sistema pueda registrar a los clientes, (su nombre, cedula, celular, ruc).
> El sistema debe esar preparado para la factura electronica y las facturas normales.
> El sistema debe ser facil de usar y se debe usar libremente, no debe ser complicado.
> El dueño quiere encontrar de manera rapida los productos que venden según el tipo de producto (baterias, cubiertas, etc.)
> El dueño espera poder visualizar el historial de compra y venta de un producto (o varios) de manera simple y eficaz, (saber cuando lo compro, de que proveedor, su estado, si se vendio: a quién se vendio y cuando). También espera con esto ver si el producto tiene salida rentable (es decir si se vende bien).

- ¿Se espera poder imprimir?
> Si, el sistema debe contar con la posibiliad de imprimir en fisico. El dueño quiere poder ver las existencias de los productos y poder imprimirlo para luego ir y verificar en su desposito con la hoja correspondiente.

- ¿Que recursos/componentes se tendrían disponibles?
> Se planea contar con una nueva notebook e impresora cuando el programa este listo.

- ¿Que productos venden?
> Neumaticos, Lubricantes, cubiertas, baterias, filtro de aire y aceite, filtro de caja.

- ¿Que servicios ofrecen?
> alineacion, balanceo, correccion de pisada.

- ¿Que detalles debemos saber sobre el servicio de alineacion?
> El dueño tiene un cuaderno donde se anotan cuantas alineaciones entran por dia, (fecha, marca del vehiculo, numero de chapa, color ddel vehiculo, monto). En realidad anota todos los servicios como alineacion directamente, no se detalla el servicio especifico.

- ¿Que detalles se debe saber sobre los clientes que solicitan servicios?
> Actualmente el dueño registra a los clientes, que de manera normal, piden algún servicio como "casual" y para algunos casos de confianza se les permite realizar un servicio y pagar más adelante en este caso se anota el nombre del cliente y se entiende que esta debiendo el servicio.

- ¿Que detalles se espera tener en cuenta sobre los productos?
> Las garantía de los mismos se debe tener en cuenta según el caso especifico del producto, en especial con las baterias. Las baterías empieza a contar su fecha de garantía desde que lo compra a su proveedor, y dependiendod e cuando lo venda este ofrece otra vez una determinada cantidad de meses, normalmente tiene un margen fijo, si la bateria tiene garantia de 18 meses según su proveedor, el ofrece una garantia de 12-13 meses para así tener almenos 5 meses para venderlo.
