*Este documento tiene un resumen del feedback recibido por el dueño del taller luego de la presentación de lo trabajado en el sprint 03.*

## Sobre las ventas
- Al dueño le gusto más el flujo actual de la pantalla de ventas.
- Se le mostró el prototipo con reparto automático editable y le pareció correcto.

## Sobre productos
- Sería bueno adaptar el flujo para editar los datos de un producto a algo más simple y con menos sobrecarga visual.
- En el sistema anterior existía un campo para precio de venta a crédito el cual puede ser distinto al precio de venta normal, sin embargo esto no es algo que nos haya indicado el dueño, faltaría confirmar en próximas reuniones si el precio unitario de un producto es distinto cuando se vende a crédito que cuando se vende a contado.
- Las funciones que más interesa pulir son las asignación de precio venta, precio compra, regitro de nuevas compras de productos.

## Sobre los servicios
- El kilometraje que se suma para el siguiente mantenimiento puede variar dependiendo del auto.
- Los kilometrajes que suelen manejar son 5mil 8mil 10mil.
- El dueño pidió para que el nomas pueda cargar el kilometraje del proximo servicio.
- El dueño quiere poder cargar la chapa del vehículo o el nombre del cliente y que aparezca los servicios que se le realizo a ese vehículo, en que fecha, el kilometraje con el que ingreso en cada orden de servicio (para mantenimiento).
- El kilometraje es unicamente necesario para la tarea de mantenimiento.
